# Figure 2 caption

**Figure 2: Raster grid — S+ (V1) / S- (V3a/d) / O+ (V4) / O++ (FEF).** Rows are the four
R-family conditions (RRRR, RXRR, RRXR, RRRX; maximum-entropy omitted-slot family). Columns are
one named exemplar unit per response class, fixed by area (V1, V3a/d, V4, FEF respectively) —
see `fig02_spiking_exemplar_rasters.py` for the hard-error selection rule (no cross-area
fallback). Each raster shows up to 40 trials aligned to p1 onset (t = 0); S- panels with fewer
than 40 available trials are resampled with replacement to exactly 40 rows. The bottom row of
each column is the PSTH (mean firing rate ± SEM, 20 ms bins) pooled across all four conditions'
correct trials for that unit.
