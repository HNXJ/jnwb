- `check_ragged_indices(path, *, table="units", probe_starts=None, probe_column=None)`: read-only check of every `<column>_index` of an NWB table, returning a `RaggedIndexReport` of `RaggedIndexCheck` rows with the flags `monotonic`, `ends_at_data_len`, `length_fits` and `offset_bug` (the multi-probe defect in which later probes' indices are offset by the first index element instead of the running total), plus ragged columns missing from `colnames`.
- `repair_ragged_index(path, column, *, ...)`: rewrites one index only when the old index equals that defect's formula and the corrected index ends at the data length and fits the dtype, raising `RaggedIndexRepairRefused` otherwise; a dry run by default, `backup_path` required to write.
- A docs page, "Repairing NWB files", on ragged-index defects, `peak_channel_id` against `waveform_mean` rows, schema consistency and the validation stack.
