- `classify_unit_quality` raises `ValueError` for empty `thresholds`, which passed every unit as `'Good'`, for a NaN or infinite threshold, which passed or failed every unit alike, and for a threshold column that occurs twice, which raised an unnamed `TypeError`; a `None` or non-numeric threshold raises `TypeError` naming it.
- `audit_units`, `assign_quality_tier` and `enrich_units_dataframe` (and `get_all_units_metadata` through it) raise `ValueError` for a NaN or infinite cut-off (`quality_threshold`, `snr_threshold`, `presence_threshold`, `stable_threshold`) and for an empty `stable_labels`, which counted every unit, none, or no label silently; a `None` cut-off raises `TypeError`.
- `assign_quality_tier` raises `ValueError` for a numpy masked array of presence or SNR with a masked entry, whose mask was dropped and the masked value read; pass `values.filled(np.nan)` to read it as missing.
- `jnwb.metadata.compare_old_new_criteria` raises `ValueError` naming the column for a class that is not `True`, `False`, 1 or 0, such as the strings `"False"` and `"no"`, which counted as included.
