- `validate_nwb(path, *, layers=None, dandi_ignore=("DANDI.NO_DANDISET_FOUND",), max_messages=50)`: validates one NWB file in six layers (`read`, `pynwb_schema`, `pynwb_core`, `integrity`, `nwbinspector`, `dandi`) and returns an `NWBValidationReport` whose `ok`, `complete` and `dandi_ready` say whether any layer failed, any was skipped, and whether the `read`, both `pynwb` and the `dandi` layers ran and passed. `pynwb_core` validates against the core namespace of the installed pynwb, so a file is checked against the newest schema that release knows. The NWB Inspector and DANDI layers need `pip install jnwb[validate]` and are reported skipped, never passed, without it.
