## Method, and what would falsify this

- `execution != verification`. Every "existing evidence" cell was established by **opening the
  test and reading the function body**, not by a grep hit. Every selector cited above was then
  resolved against the AST of its module and confirmed class-qualified — 16 of 16 resolve
  (06-28's rule: a bare test name collects nothing and reads as a kill).
- Each chain was checked against all six silently-changing invariants (shapes, units, coordinate
  frames, timestamps, sample rates, 0- against 1-indexing). The classes that landed are
  index-base (H1, H8), coordinate-frame (H2), shape/axis (H3, H4), ordering (H5, H6, H9a, H9b)
  and dropped-NaN (H7). **Two of the six produced no chain, each for a measured reason.**
  *Timestamps*: the `event_onsets` (seconds) → `epoch_continuous(onset_unit=…)` boundary is
  already defended — onsets in the wrong unit yield an all-NaN epoch **and** a `UserWarning`
  naming that exact mistake ("onsets in milliseconds read as seconds land here"), reproduced.
  *Sample rates*: `acquisition_channel` returns `(data, rate_hz)` as one tuple and `inspect()`
  carries `rate_hz` per series, so the rate travels with the data it describes; no jnwb boundary
  re-derives a rate, and separating the two takes a deliberate substitution at the call site.
- One hypothesis was reproduced and **killed**: H1 under a simple channel *reversal* is
  permutation-covariant (0 of 24 labels change), because `probe_geometry` re-derives its
  principal direction from the coordinates. Only a table order that is non-monotone in depth
  separates the two index spaces. A discriminator built on a reversal would have passed and
  proved nothing.
- Falsifiers, stated so the ruling can be attacked: H1 is a defect only if an electrode table
  whose row order is not depth order is a shape jnwb intends to accept — if the contract is that
  callers must depth-sort first, H1 becomes a documentation-and-refusal item. H2 and H3 are
  defects only if the library owes a caller a refusal on a transposed array rather than a
  documented axis; if the ruling is that the default axis is the contract, both collapse to
  06-24 rows. H6 turns on whether `how=` may name an estimand the input can no longer support.
