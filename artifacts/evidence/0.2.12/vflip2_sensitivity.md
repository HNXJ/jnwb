## Method

- Bin width 2 Hz: each output bin is the mean of two adjacent 1 Hz bins; its label is the even one. Bin width 0.5 Hz: linear interpolation at half-hertz labels within the input range. The power example has only its PSD, so it has no FFT-length route.
- Upper frequency: the columns labelled at most the value; a value above the last label is not run.
- Contact spacing 200 um: every second row. 50 um: linear interpolation between rows, midpoints inserted.
- Flip rows: row order reversed, orientation "both".
- omega_cut changes acceptance only: accepted is omega > omega_cut.

Reproduce: `python scripts/vflip2_sensitivity.py --write` with the tree as the working directory.
