# vFLIP Reference Difference Table (0.2.2-01)

## Executive Summary

This document establishes the authoritative reference comparison for `jnwb.laminar.vflip`,
`jnwb.laminar.vflip_from_lfp`, and `jnwb.laminar.label_layers` prior to implementation in `0.2.2-02`.
It compares three sources across all consequential operations:
1. **Contributed / Private Implementation**: `ae906a4:codes/functions/vflip2_mapping.py` (`vFLIP2`);
2. **Publication / Reference Algorithm**: Mendoza-Halliday et al. (2024) / Bastos et al. (2018);
3. **Proposed `jnwb.laminar` API**: Non-interactive, geometry-aware, unit-safe public library primitives.

Every difference is classified into one of:
- `IDENTICAL`: Identical mathematical formulation and execution.
- `EQUIVALENT`: Same mathematical mapping under stated assumptions, proven algebraically or numerically.
- `INTENTIONAL JNWB CHANGE`: Deliberate design change with explicit scientific/engineering justification and stated exact difference.
- `UNRESOLVED`: Open ambiguity requiring maintainer resolution (must be empty to proceed).

## Authoritative Reference Table

| Operation / Dimension | Contributed Implementation (`vFLIP2`) | Publication / Reference (Mendoza-Halliday et al. 2024) | Proposed `jnwb.laminar` API | Classification | Exact Difference & Rationale |
|---|---|---|---|---|---|
| **1. Input Representation** | `data`: `(n_channels, n_freqs)` array with `DataType` (`"psd"`, `"power"`, `"amplitude"`); `area_labels` strings; `valid_channel_mask`; `bad_channel_mask`. | LFP power spectral density matrix across laminar depth contacts $c \in \{1, \dots, C\}$ and frequencies $f \in [f_{\min}, f_{\max}]$. | `psd: np.ndarray` `(n_channels, n_freqs)` in $(U_{\text{in}})^2/\mathrm{Hz}$; `freqs: np.ndarray` `(n_freqs,)` in $\mathrm{Hz}$; optional `ProbeGeometry`. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code accepts ad-hoc area strings and manual masks. jnwb requires plain numerical arrays and structured geometry.<br>**Rationale**: Decouples laminar estimation from downstream area taxonomies, condition labels, and manual strings. Explicit frequency coordinates (`freqs`) prevent bin-width scaling errors under arbitrary frequency resolutions. |
| **2. Frequency Selection** | Grid search over a hardcoded 4-row matrix (`SpectralProfile`: combinations of low 0–30 Hz and high 30–150 Hz). | Evaluates spectrolaminar contrast between alpha/beta (8–30 Hz) and gamma (50–150 Hz). | Explicit `band_low: Tuple[float, float]` and `band_high: Tuple[float, float]`, defaulting to canonical $(8.0, 30.0)$ and $(50.0, 150.0)\,\mathrm{Hz}$. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code searches across a discrete 4-row profile grid. jnwb requires explicit band bounds.<br>**Rationale**: Eliminates unconstrained combinatorial grid search that overfits to specific recordings; gives callers transparent, explicit control over the physiological frequency bands under test. |
| **3. Spectral Normalization** | Columnwise z-score across channels per frequency: $\tilde{P}(c, f) = (P(c, f) - \mu_c(f)) / (\sigma_c(f) + \epsilon)$. | Relative power or depth standardization per frequency across contacts along the shaft. | Min-max relative power per frequency across contacts: $\tilde{P}(c, f) = (P(c, f) - \min_k P(k, f)) / (\max_k P(k, f) - \min_k P(k, f))$, and each band depth profile rescaled to $[0, 1]$ across contacts before they are differenced to locate the crossover. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: jnwb used the contributed columnwise z-score through 0.2.3 and replaced it in 0.2.4.<br>**Rationale**: z-scoring forces every frequency column to zero mean across contacts, so both band profiles carry zero spatial mean and $\Delta(c) = H(c) - L(c)$ sums to zero identically. The zero crossing of a zero-sum profile sits near the centre of the sampled contacts whatever the true crossover is, and for a profile linear in contact index it is pinned to the midpoint exactly. Measured on the shipped path at SNR 100, true crossovers of 5.5 / 7.5 / 11.5 / 15.5 / 18.5 returned bias +3.98 / +2.17 / -0.01 / -1.92 / -4.75 contacts, matching the removed spatial mean to within 0.5. The literature's other reading, the relative power fraction $P(c, f) / \sum_k P(k, f)$, was implemented and measured before this choice was made: being simplex-constrained it fixes each column's sum, so $\Delta(c)$ again sums to zero and the bias is unchanged (+3.81 / +2.25 / +0.11 / -1.79 / -4.43). Any normalization constraining a column's mean or sum carries the defect. Min-max constrains the extremes instead, leaving the spatial mean free to carry the location; the band-profile rescaling then removes the differing additive background each analysis band contributes. Shaft-wide median $|c^* - c_{\text{true}}|$ at SNR 100 falls from 2.28 to 0.99 contacts, and the old estimator's residual does not fall with SNR because it is bias. Calibrated in `artifacts/benchmarks/vflip_calibration_0.2.4.md`. |
| **4. Spatial Ordering** | Assumes matrix rows $0 \dots C-1$ directly match linear physical order along probe shaft. | Assumes contacts ordered linearly from cortex surface (superficial) to deep (or vice versa). | Requires verified monotonic order via `ProbeGeometry.linear_order` or pre-sorted input array. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code assumes row index is spatial sequence. jnwb verifies physical layout.<br>**Rationale**: Eliminates assumptions about row order in unvalidated tables; integrates with `probe_geometry` to enforce verified physical layout along the shaft. |
| **5. Orientation** | Accepts `"superficial"`, `"deep"`, or `"both"`, mapped to $1, -1, 0$. Uses sign-zeroing heuristic in grid search. | Superficially dominant gamma yields to deep-dominant alpha/beta; penetration angle or approach determines sign. | Accepts `orientation: str = "auto" \| "superficial_to_deep" \| "deep_to_superficial"`. Resolved in `VFlipResult.orientation`. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code uses ambiguous labels (`"superficial"`, `"deep"`, `"both"`) with sign-zeroing heuristics inside an empirical grid search loop. jnwb uses explicit directional descriptors (`"superficial_to_deep"`, `"deep_to_superficial"`, `"auto"`) based on increasing channel index along the shaft.<br>**Rationale**: Unambiguous directional semantics. Under `"auto"`, evaluates empirical peak channel ordering ($\text{sign}(c_{\text{low}} - c_{\text{high}})$) and signs $\Delta(c)$ accordingly, returning the resolved orientation explicitly. |
| **6. Contact Spacing** | `intdist: float` in $\mathrm{mm}$ (default $0.05\,\mathrm{mm} = 50\,\mu\mathrm{m}$). Used for mid-zone width calculation. | Inter-contact pitch determines spatial resolution; crossover reported in distance ($\mu\mathrm{m}$ or $\mathrm{mm}$). | Explicit `contact_spacing: float` in $\mu\mathrm{m}$ (or derived from `ProbeGeometry.nominal_pitch`). | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code defaults to mm and accepts NaN. jnwb requires explicit $\mu\mathrm{m}$.<br>**Rationale**: Adheres to strict library-wide micrometer ($\mu\mathrm{m}$) coordinate standard. Enforces pitch uniformity (`is_uniform=True`). |
| **7. Missing & Bad Contacts** | Splices probe into contiguous clean segments; discards any segment with length $< 8$ channels. | Spatial masking or interpolation along cortical column. | Accepts optional `bad_channel_mask: np.ndarray[bool]`; uses 1D linear interpolation along depth for gradient/profile; reports missing count in result. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code discards non-contiguous channels. jnwb interpolates isolated bad channels along depth.<br>**Rationale**: Prevents discarding entire probes due to a single isolated bad contact, while preserving strict rejection if valid coverage is insufficient ($< 8$ contacts). |
| **8. Profile Gradient** | Band averages: $L(c) = \text{mean}_{f \in \text{low}} \tilde{P}(c, f)$, $H(c) = \text{mean}_{f \in \text{high}} \tilde{P}(c, f)$; difference $\Delta(c) = H(c) - L(c)$. | Difference between normalized gamma power and normalized alpha/beta power along depth. | Difference profile $\Delta(c) = H(c) - L(c)$ (oriented along superficial $\to$ deep). | **IDENTICAL** | $\Delta(c)$ evaluates the local dominance of high vs low frequency oscillatory power at contact $c$. |
| **9. Crossover Estimator** | Initial discrete zero-crossing: $\text{argmin}_{c \in \text{candidates}} \|\Delta(c)\|$; refined on discrete integer channels via score: $-\|\Delta(c)\| + 0.25 \|\nabla \Delta(c)\|$ after 3-tap uniform filtering. | Zero-crossing / inflection point where standardized gamma equals standardized alpha/beta power. | Continuous zero-crossing via linear sub-contact interpolation of $\Delta(c) = 0$; optional gradient refinement. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code selects only discrete integer channels using a 3-tap filtered heuristic. jnwb computes continuous linear sub-contact root-finding: $c^* = c_i + \frac{-\Delta(c_i)}{\Delta(c_{i+1}) - \Delta(c_i)}$.<br>**Rationale**: Continuous interpolation eliminates integer channel discretization errors, providing true physical depth resolution along the shaft. Discrete channel indices are available via rounding $\lfloor c^* \rceil$. |
| **10. Objective Function & Support Score ($\Omega$)** | Metric: $\Pi = P_{s,\text{dist}} \cdot D_{\text{band}} \cdot \|\text{goodness}\| \cdot \Delta c_{\text{peaks}} \cdot N_{\text{low}} \cdot N_{\text{high}}$; support score $\Omega = \ln(\Pi)$. | Evaluates separation between supragranular gamma peak and infragranular alpha/beta peak across contacts. | Evaluates peak separation, contrast magnitude, and transition monotonicity; computes support score $\Omega$. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code deletes $\Omega$ when below threshold (`Results = None`). jnwb returns $\Omega$ on all runs.<br>**Rationale**: Support score $\Omega$ is returned in `VFlipResult` on ALL runs, including rejected fits, ensuring diagnostic inspectability and calibration. |
| **11. Acceptance & Rejection Semantics** | `omega_cut: float = 6.0`. If $\Omega < \text{omega\_cut}$, returns `Results = None`. In tests, allowed $\Omega_{\text{cut}} = -\infty$ to force fit. | Probes lacking clear spectrolaminar motif or with low contrast are considered non-identifiable. | `min_support_score: float = 6.0`. If $\Omega < \text{min\_support\_score}$, returns `accepted=False`, `crossover_contact=None`. No $-\infty$ bypass. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code used None result and allowed $-\infty$ test bypass. jnwb returns structured dataclass with `accepted=False` and `None` parameters.<br>**Rationale**: Strictly conforms to jnwb frozen failure semantics (0.2.0-07): rejected fits return `accepted=False` and `None` for crossover; never fabricate plausible numbers or allow silent bypass. |
| **12. Layer Classification (`label_layers`)** | `get_laminar_label_vector()`: Centers mid zone of width $\lceil \text{layer4} / \text{pitch} \rceil$ on crossover; assigns `"sup"`, `"mid"`, `"deep"`, `"na"`. Hardcoded 128 channels. | Granular layer (L4) centered at crossover; superficial (L1–3) above; deep (L5–6) below. | `label_layers(vflip_result, probe_geom, *, granular_thickness_um=400.0) -> dict[Any, str]`. Assigns `"superficial"`, `"input"`, `"deep"`, `"na"`. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code hardcodes 128 channels and uses `"sup"`/`"mid"`. jnwb dynamically indexes arbitrary arrays, uses explicit $\mu\mathrm{m}$ units, maps all channels to `"na"` on rejection, and uses standard anatomical terminology.<br>**Rationale**: Arbitrary channel count; explicit $\mu\mathrm{m}$ layer 4 thickness; rejected fits yield all `"na"`. |
| **13. Interactive Hooks & Display** | Contained `plot_result: bool`, matplotlib plotting logic, and historical prompt hooks. | Computational method described in paper text and figures. | Strict, headless, non-interactive functional implementation. Zero GUI/plotting side effects in core estimator. | **INTENTIONAL JNWB CHANGE** | **Exact difference**: Contributed code embedded plotting/interactive options. jnwb is pure headless computation.<br>**Rationale**: Core library functions must remain headless, fast, and pure. Visualizations belong in `visual_qc` or examples. |
| **14. Determinism & Randomness** | Deterministic mathematical optimization. Zero RNG calls. | Deterministic algorithm. | Strictly deterministic. Zero RNG calls. | **IDENTICAL** | Guarantees exact reproducibility across calls and runs on identical input arrays. |

## Resolution Status

- **IDENTICAL items**: 2 (Spectral-gradient difference profile $\Delta = H - L$, Deterministic execution)
- **EQUIVALENT items**: 0 (Every non-identical item is formally classified as an intentional change with exact mathematical difference stated)
- **INTENTIONAL JNWB CHANGES**: 12 (Input decoupling, Explicit band bounds, Standardized z-score depth normalization, Geometry integration, Unambiguous orientation enum, Explicit $\mu\mathrm{m}$ pitch standard, Bad-contact depth interpolation, Continuous sub-contact zero-crossing, Always-returned support score $\Omega$, Frozen failure semantics without $-\infty$ bypass, Dynamic layer labeling with strict `"na"` rejection, Pure headless execution)
- **UNRESOLVED items**: **0 (None)**.

Every consequential difference is identified, derived, or scientifically justified. The reference contract is established and frozen for implementation in `0.2.2-02`.
