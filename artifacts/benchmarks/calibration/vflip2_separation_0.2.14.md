# vFLIP-vFLIP2 separation agreement threshold (15-18)

Qualifies release 0.2.14. Generated by `python scripts/calibrate_vflip2_separation.py` from estimator SHA-256 `b2502142dab9870c` (vFLIP) and `6aa906f40c2de637` (vFLIP2); declared package version 0.2.13 at generation; 400 null draws. Environment: jnwb 0.2.13, numpy 2.4.6, scipy 1.18.0, Python 3.14.3.

All recordings are synthetic: `jnwb.testing.synth_laminar_motif` at `snr=0` and no other generator. No project session is used.

## Method

- Probe: 32 contacts at fs 1000 Hz, pitch 100 um, `c_crossover=16` (immaterial at `snr=0`), `8000` samples per draw. Each draw comes from a successive child of the seeded `rng`, so one seed rebuilds the whole distribution.
- Both estimators run with their acceptance gates open (`min_support_score` and `omega_cut` at -1e+09, finite, so no sentinel bypasses the acceptance logic). With the gates closed almost no null draw holds both crossovers, so the percentile would rest on a handful of joint acceptances; open, the gap is the structural-crossover disagreement on noise.
- Gap: `|vflip2_crossover - vflip_crossover|` in contact spacings, the quantity `fuse_laminar_anchors` reports as `separation_contacts`. A draw where either crossover is structurally absent leaves the gap undefined and is counted, not filled in.
- Threshold T: the 95th percentile of the defined gaps, `22.8002` contact spacings. `fuse_laminar_anchors` reads `'agree'` at or below T, `'disagree'` above it, and `'unresolved'` when the gap is undefined.

## Result

- Draws: 400; defined gaps 117; undefined 283.
- T (95th percentile): `22.8002` contact spacings.
- Median defined gap: `8.3569`; largest: `27.2767`.

## Sources of the numbers

- Gaps and T: recomputed from `trials` in the raw record; the percentile is `numpy.percentile` with its default linear interpolation.
- Estimator code: the SHA-256 rule of `scripts/calibrate_xflip.py` that `scripts/calibrate_vflip.py` also uses (raw key `estimator_sha256`).
- Declared version: `jnwb/__init__.py` (raw key `declared_version`); release set in `scripts/calibrate_vflip2_separation.py`.
- Versions: raw key `environment`.
