# Curation calibration: defaults of `curate_and_label`

Qualifies release 0.2.13. Generated by `python scripts/calibrate_curation.py` from estimator SHA-256 `a7069e76ec6d3429`; declared package version 0.2.12 at generation; 24 seeds per cell; 2784 trials. Environment: jnwb 0.2.12, numpy 2.4.6, scipy 1.18.0, Python 3.14.3.

All recordings are synthetic: `jnwb.testing.synth_vflip2_crossover` and its null. No project session is used.

## Method

- Probe: 32 contacts at fs 1000 Hz. The crossover contact `z0` is drawn uniformly from 10 to 21, both ends included, from the seed's generator; the planted probe has `snr=4`. The null is the same draws with `snr=0`, so it shares the planted probe's background and sources.
- Epoch layout: `curate_and_label` takes (channels, epochs, samples), and the generator returns (channels, samples). Each probe is therefore 40 epochs of 1000 samples, and each epoch is one successive draw of the generator at the probe's `z0` and `snr`. This is the layout of `tests/test_laminar_curation.py` (`synth`: `n_ep=40`, `n_s=1000`), used as the fallback the calibration packet names.
- Truth: 100 * `z0` um. `anchor_um` is `crossover_contact * pitch` (`jnwb/laminar_curation.py:957`). `crossover_contact` is a 0-based row index (`jnwb/laminar/_vflip.py:639-653`), and the planted band weights are equal at contact `z0` (`jnwb/testing/synth.py:587-588`). Positions run from the first contact, with no half-pitch offset.
- Recovery: `|anchor_um - truth_um| <= 100` um, one pitch with the bound included. A NaN anchor is not recovered. The grade does not enter this column: a grade F anchor is the motif crossing, kept with no claim on it, and counts here when it lies within the tolerance. The second recovery column counts only grades A to D. False acceptance: a null probe graded A or B.
- Intervals: exact two-sided 95% Clopper-Pearson, `jnwb.clopper_pearson`.
- Sweep: each parameter alone at its default times 0.5, 0.75, 1, 1.5 and 2, with every other argument at default. An int default rounds to the nearest int with Python's `round`, which sends a tie to the even integer, as `scripts/calibrate_vflip.py` rounds; it is held at least 1. A fraction is clipped to at most 1.0. A value equal to the default, or already listed, is dropped, so the default is always the x1 row.
- Refusal: a value whose trial raises `ValueError` is recorded as refused, with the message, and has no rates.
- Stable range: the values whose recovery interval overlaps the interval of the highest-recovery value, and whose false-acceptance interval overlaps the default's. A default outside its stable range is FLAGGED. The script changes no default.
