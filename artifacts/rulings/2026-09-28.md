# Rulings of 2026-09-28

Made by Hamm during the 0.2.7 cycle, with the integrator's graded choices marked as such. Each ruling names the work it creates; that work is executed through `artifacts/todo_stack.md`.

| Item | Ruling | Work it creates |
|---|---|---|
| `xflip` count when several counts tie at the smallest surrogate p | **The count whose observed contrast is the most surrogate standard deviations above the surrogate mean, then the smallest count**; under real structure every count sits at the p floor and this rule decides, so the docstring says so; the omnibus p does not depend on it | IB-84 |
| `xflip` count under `n_blocks=None` with no surrogates (integrator, 80) | Count 2 is reported, nothing is accepted, and the reason says the test did not run | IB-84 |
| Ties between a permutation draw and the observed statistic (integrator, 90) | One helper counts a draw within `100*eps*abs(observed)` as at least as extreme, the width `scipy.stats.permutation_test` uses; an existing absolute width stays where it is wider | P-345 |
| `phase_slope_index` jackknife spread at round-off (integrator, 85) | Below `8*eps*n_seg*n_pairs` z and p are undefined and `ok_for_interpretation` is False, with a warning | P-331 |
| `jrsa` refusal of an `adim` the resampling ignores (integrator, 85) | Refused only when the null, bootstrap or lag acts on an axis `adim` does not name, which keeps the documented reduced-axis case | IB-49 |
| `jrsa` row-metric `window` at the default `adim` (integrator, 70) | Stated in the docstring and `docs/03` with a test; windowing the observation axis by default is 0.2.8 work | IB-58 |
| Unsorted spike times in `UnitAnalyzer.quality_metrics` (integrator, 85) | Sorted, as `raster_psth` accepts any order; a spike train has no meaningful order | P-332 |
| A held item deleted after the closure receipt (integrator, 80) | Counts as done only when the receipt's `finished after the pass` row names it | P-353 |
