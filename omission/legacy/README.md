# `legacy/` — archived, superseded material

**Purpose:** things that used to be live and are kept for provenance, not for use. If you are
about to import from here or cite a number from here, stop — check `../context/PROJECT_STATE.md`
for the current replacement first.

**Owns:** `context/` (old context docs), `docs/adr/`, `docs/constitution/` (old
architecture-decision/doctrine docs, superseded by root and project `CLAUDE.md`), `examples/`,
`markdowns/`.

**Does not own:** anything a current script, test, or skill imports or cites by path — nothing
here should have a live inbound reference; if you find one, that's a stale-reference bug in the
referrer, not a reason to un-deprecate this folder.

**How to apply:** read for historical context only. Never treat content here as a current
scientific source or a current API surface.
